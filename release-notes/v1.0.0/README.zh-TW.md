# OpenStandBy v1.0.0

[English](README.md)

OpenStandBy 的第一個正式版本。把 Android 手機橫放在桌面底座上，就能查看正在播放的歌曲、控制播放或看時間。OpenStandBy 開著時會保持螢幕常亮。

## 功能

- **音樂播放器**顯示歌名、歌手與專輯封面。可播放、暫停、切歌，音樂 App 支援時也能拖曳進度條。
- **同步歌詞**會隨播放進度捲動並標示目前這一行。可匯入 `.lrc`、`.yrc`、`.txt` 檔，也能在裝置上將簡體歌詞轉為繁體。
- **時鐘與 GPS 時速表**可從播放器往上滑看時鐘，往下滑看時速表。時鐘有數位、指針、翻頁和七段顯示四種樣式，兩個畫面都可以各自設定照片背景。
- **介面語言**支援繁體中文（台灣）、英文與跟隨系統。
- **更新通知**會在 GitHub 發布較新的正式版本時提醒，點一下就能開啟下載頁。

## 安裝

支援 **Android 9 以上**。到 v1.0.0 發布頁的 **Assets** 下載並安裝 `OpenStandBy-v1.0.0.apk`。

依照畫面提示允許通知存取，播放器才能讀取正在播放的歌曲。接著在 Spotify、YouTube Music 或其他支援 Android 媒體工作階段的 App 播一首歌。使用 GPS 時速表時，請允許精確位置權限。

遇到問題，歡迎到 [GitHub Issues](https://github.com/seven-317/OpenStandBy/issues) 回報。
