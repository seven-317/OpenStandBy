# OpenStandBy v1.0.2

[繁體中文](README.zh-TW.md)

- Added Kugeci as a fallback for line-synced lyrics. Check **Lyrics options** to see the source.
- Improved song matching for LRCLIB and LRCMux using the title, artist, and track length when available.
- The app compares LRCMux lyrics with Kugeci when both have timed results to catch mix-ups between songs such as an original track and its sequel.
