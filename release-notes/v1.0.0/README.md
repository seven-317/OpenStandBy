# OpenStandBy v1.0.0

[繁體中文](README.zh-TW.md)

The first public release of OpenStandBy. Set your Android phone on a desk dock in landscape to see what's playing, control playback, or check the time. OpenStandBy keeps the screen on while it's open.

## What's included

- **Music player.** See the track, artist, and album cover. Play, pause, skip tracks, and seek when your music app supports it.
- **Synced lyrics.** Follow the current line as the song plays. Import `.lrc`, `.yrc`, and `.txt` files or convert Simplified Chinese lyrics to Traditional on the device.
- **Clock and GPS speedometer.** Swipe up from the player for the clock or down for the speedometer. Choose a digital, analog, split-flap, or seven-segment clock face. Both screens support their own photo background.
- **Interface language.** Choose English, Traditional Chinese (Taiwan), or follow the system language.
- **Update alerts.** OpenStandBy checks GitHub for newer stable versions. Tap an alert to open the download page.

## Install

Requires **Android 9 or later**. Download and install `OpenStandBy-v1.0.0.apk` from **Assets** on the v1.0.0 release page.

Grant notification access when prompted so the player can read what's playing. Start a track in Spotify, YouTube Music, or another music app that exposes an Android media session. Allow precise location when using the GPS speedometer.

Report issues on [GitHub Issues](https://github.com/seven-317/OpenStandBy/issues).
