# OpenStandBy

An open-source StandBy mode for Android.

OpenStandBy aims to bring a clean, customizable horizontal display to Android devices—whether mounted on a motorcycle/car or resting on a desk dock. 

Currently, the project focuses on Phase 1: A distraction-free landscape music controller with large album art, ride-friendly buttons, and real-time synced lyrics. It works out of the box with Spotify, YouTube Music, and other media apps without requiring logins or API keys.

### 🗺️ Roadmap
- [x] Phase 1: Music Dock (Current Focus)
  - Full-screen landscape player via Android MediaSession
  - Large, glove-friendly playback controls & dynamic blurred background
  - Real-time synced .lrc lyrics (powered by LRCLIB)
- [ ] Phase 2: StandBy Widgets (Planned)
  - Swipeable horizontal pages (Flip clock, minimalist digital clock, calendar)
  - GPS Speedometer & navigation shortcuts for riders
  - OLED burn-in protection & night mode
